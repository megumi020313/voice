# 模型与数据下载说明

仓库中**未包含**以下大文件（超过 GitHub 限制），克隆后需自行下载或运行脚本生成。

## 1. Faster-Whisper (ASR)

- **路径**: `models/faster-whisper-large-v3/`（或 `models/models--Systran--faster-whisper-large-v3/`）
- **获取方式**（任选其一）:
  ```bash
  cd remote/remote-v2
  python scripts/setup_faster_whisper.py
  ```
  或从 [Hugging Face: Systran/faster-whisper-large-v3](https://huggingface.co/Systran/faster-whisper-large-v3) 下载到对应目录。

## 2. ERes2NetV2 声纹权重

- **路径**: `models/eres2netv2/pretrained_eres2netv2.ckpt`
- **获取方式**: 从项目提供链接或内部存储获取，放置到上述路径。

## 3. Silero VAD

- **路径**: `models/vad/`
- **说明**: 若使用 `scripts/setup_vad.py` 或从 Silero 官方仓库获取，将完整目录放到 `models/vad/`。

## 4. Cohort（S-Norm 用）

- **路径**: `data/vector_db/cohort.npy`
- **获取方式**: 运行 `python scripts/build_cohort.py` 生成，或从已有环境拷贝。

完成上述步骤后再启动 API / Web 服务。
