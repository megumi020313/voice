# 优化任务管理

## 概述
本目录用于管理优化任务，包括性能优化、代码优化、架构优化等。

## 优化文档规范

### 文档命名
- 格式：`OPT-YYYYMMDD-序号-优化描述.md`
- 示例：`OPT-20251224-001-数据库查询性能优化.md`

### 文档内容
每个优化文档必须包含：
- 优化信息（状态、优先级、负责人、时间）
- 优化目标（目标、预期效果、性能指标）
- 现状分析（当前实现、存在问题、性能瓶颈）
- 优化方案（优化模块、函数、内容、模块化设计）
- 优化效果（优化前后对比、性能提升）
- 测试验证（验收清单）
- YesDev任务（任务ID、状态）

## 优化分类

- **性能优化**: 响应时间、吞吐量、资源使用等性能相关优化
- **代码优化**: 代码结构、可读性、可维护性等代码质量优化
- **架构优化**: 系统架构、模块设计、依赖关系等架构相关优化
