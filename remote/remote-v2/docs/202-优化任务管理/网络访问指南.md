### 2. 外网访问（互联网）

#### 方案A：使用内网穿透工具（推荐）

**使用 ngrok**：
```bash
# 安装 ngrok
# 访问 https://ngrok.com/ 注册账号

# 启动穿透（Web服务）
ngrok http 5001

# 启动穿透（API服务，新终端）
ngrok http 8000
```

**使用 frp**：
```bash
# 需要有公网服务器
# 配置 frpc.ini
[web]
type = tcp
local_ip = 127.0.0.1
local_port = 5001
remote_port = 5001

[api]
type = tcp
local_ip = 127.0.0.1
local_port = 8000
remote_port = 8000
```

**使用 Cloudflare Tunnel**：
```bash
# 安装 cloudflared
# 配置隧道
cloudflared tunnel --url http://localhost:5001
```

#### 方案B：配置路由器端口转发

1. 登录路由器管理界面（通常是 192.168.1.1 或 192.168.0.1）
2. 找到"端口转发"或"虚拟服务器"设置
3. 添加转发规则：
   - 外部端口：5001 → 内部IP：10.8.21.33，内部端口：5001
   - 外部端口：8000 → 内部IP：10.8.21.33，内部端口：8000
4. 获取公网IP：访问 https://ip.cn/
5. 通过 `http://你的公网IP:5001` 访问

**⚠️ 安全警告**：
- 端口转发会将服务暴露到公网，存在安全风险
- 建议配置防火墙规则，限制访问IP
- 建议添加身份验证机制

## 🔒 安全配置（可选）

### 1. 配置防火墙（仅允许特定IP访问）

```bash
# 启用防火墙
sudo ufw enable

# 允许本机访问
sudo ufw allow from 127.0.0.1 to any port 5001
sudo ufw allow from 127.0.0.1 to any port 8000

# 允许局域网访问（假设局域网是 10.8.0.0/16）
sudo ufw allow from 10.8.0.0/16 to any port 5001
sudo ufw allow from 10.8.0.0/16 to any port 8000

# 允许特定IP访问（替换为实际IP）
sudo ufw allow from 192.168.1.100 to any port 5001
sudo ufw allow from 192.168.1.100 to any port 8000

# 查看规则
sudo ufw status
```

### 2. 配置Nginx反向代理（推荐生产环境）

```nginx
# /etc/nginx/sites-available/remote-v2
server {
    listen 80;
    server_name your-domain.com;

    # Web界面
    location / {
        proxy_pass http://127.0.0.1:5001;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    # API服务
    location /api/ {
        proxy_pass http://127.0.0.1:8000/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

启用配置：
```bash
sudo ln -s /etc/nginx/sites-available/remote-v2 /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

### 3. 配置HTTPS（使用Let's Encrypt）

```bash
# 安装 certbot
sudo apt install certbot python3-certbot-nginx

# 获取证书
sudo certbot --nginx -d your-domain.com

# 自动续期
sudo certbot renew --dry-run
```

## 📋 故障排查

### 问题1：无法从其他设备访问

**检查清单**：
- [ ] 服务是否正在运行？`ps aux | grep python`
- [ ] 端口是否监听？`netstat -tuln | grep -E ':(5001|8000)'`
- [ ] 防火墙是否阻止？`sudo ufw status`
- [ ] 设备是否在同一网络？`ping 10.8.21.33`
- [ ] IP地址是否正确？`hostname -I`

**解决方案**：
```bash
# 1. 检查服务状态
ps aux | grep "python.*app.py"
ps aux | grep "python.*src.api.app"

# 2. 重启服务
# 停止现有服务（Ctrl+C）
# 重新启动
cd /home/swufe/Project/zhoulonghao/remote/remote-v2
conda activate vioce
python web/app.py  # 新终端1
python -m src.api.app  # 新终端2

# 3. 检查端口占用
sudo lsof -i :5001
sudo lsof -i :8000
```

### 问题2：手机无法访问

**可能原因**：
1. 手机和电脑不在同一WiFi网络
2. 路由器隔离了设备（AP隔离）
3. 手机浏览器缓存问题

**解决方案**：
1. 确保连接同一WiFi
2. 关闭路由器的"AP隔离"功能
3. 使用手机浏览器的无痕模式
4. 清除浏览器缓存

### 问题3：API调用失败

**检查前端配置**：
前端需要配置正确的API地址。编辑 `web/static/js/api.js`：

```javascript
// 如果是局域网访问，需要修改API地址
constructor() {
    // 本机访问
    this.baseURL = 'http://localhost:8000/api/v1';
    
    // 局域网访问（其他设备访问时）
    // this.baseURL = 'http://10.8.21.33:8000/api/v1';
    
    // 自动检测
    // const host = window.location.hostname;
    // this.baseURL = `http://${host}:8000/api/v1`;
}
```

**推荐配置（自动检测）**：
```javascript
constructor() {
    // 自动使用当前主机名
    const host = window.location.hostname === 'localhost' ? 
        'localhost' : window.location.hostname;
    this.baseURL = `http://${host}:8000/api/v1`;
}
```

```bash
cd /home/swufe/Project/zhoulonghao/remote/remote-v2

# 后台启动API服务
nohup python -m src.api.app > logs/api.log 2>&1 &

nohup python web/app.py > logs/web.log 2>&1 &

# 查看日志
tail -f logs/api.log
tail -f logs/web.log
```

### 使用systemd服务（推荐生产环境）

创建服务文件 `/etc/systemd/system/remote-v2-api.service`：
```ini
[Unit]
Description=Remote-V2 API Service
After=network.target

[Service]
Type=simple
User=swufe
WorkingDirectory=/home/swufe/Project/zhoulonghao/remote/remote-v2
ExecStart=/home/swufe/miniconda3/envs/vioce/bin/python -m src.api.app
Restart=always

[Install]
WantedBy=multi-user.target
```

创建服务文件 `/etc/systemd/system/remote-v2-web.service`：
```ini
[Unit]
Description=Remote-V2 Web Service
After=network.target

[Service]
Type=simple
User=swufe
WorkingDirectory=/home/swufe/Project/zhoulonghao/remote/remote-v2
ExecStart=/home/swufe/miniconda3/envs/vioce/bin/python web/app.py
Restart=always

[Install]
WantedBy=multi-user.target
```

启用服务：
```bash
sudo systemctl daemon-reload
sudo systemctl enable remote-v2-api
sudo systemctl enable remote-v2-web
sudo systemctl start remote-v2-api
sudo systemctl start remote-v2-web
sudo systemctl status remote-v2-api
sudo systemctl status remote-v2-web
```
