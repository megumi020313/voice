## 方案2：进度条平滑优化（自适应学习 + 三段式弹性策略）

### 2.1 核心思路

**问题1**：当前进度条按固定百分比分配，导致"跳跃后卡住"  
**问题2**：静态模拟会因性能优化而失效（如RTF从0.128降至0.08后，进度条会"跑太快"）

**解决方案**：**自适应学习 + 三段式弹性进度条**

1. **自适应RTF学习**：
   - 前端维护`CURRENT_RTF`变量（初始0.128）
   - 每次识别完成后，计算实际RTF并更新（取最近5次平均）
   - 下次识别自动使用最新RTF预估

2. **三段式弹性进度条**：
   ```
   0% [========= 自适应模拟区 ==========> | 90% ] --- 缓冲区 --- [ 100% ]
   ```
   - **0%-90%**：基于`CURRENT_RTF`匀速增长
   - **90%-95%**：极慢蠕动（每秒0.1%），等待后端
   - **95%-100%**：后端返回后瞬间跳转

3. **后端性能埋点**（可选）：
   - 后端返回各阶段耗时（`latency_stats`）
   - 前端自动校准权重系数
   - 进度条随优化自动变准

### 2.2 推荐权重分配

基于性能分析数据（RTF=0.128）：

| 阶段 | 权重 | 进度区间 | 说明 |
|------|------|----------|------|
| 音频预处理 & VAD | 10% | 0% - 10% | 处理较快，作为启动反馈 |
| SV特征提取 & ASR并发 | 60% | 10% - 70% | **核心耗时区**，进度匀速移动 |
| Diarization智能引擎 | 25% | 70% - 95% | 包含对齐、边界校正（V3.3）、平滑修正（V3.4） |
| 结果生成与输出 | 5% | 95% - 100% | 最后收尾 |

#### 2.3.1 自适应RTF管理器

首先在`web/static/js/main.js`中添加RTF管理器：

```javascript
/**
 * 自适应RTF管理器
 * 功能：学习历史性能数据，动态调整RTF预估值
 */
class AdaptiveRTFManager {
    constructor() {
        this.storageKey = 'voiceprint_rtf_history';
        this.maxHistorySize = 5; // 保留最近5次记录
        this.defaultRTF = {
            recognize: 0.128,  // 识别默认RTF
            register: 0.05     // 注册默认RTF
        };
        this.loadHistory();
    }
    
    /**
     * 从localStorage加载历史数据
     */
    loadHistory() {
        try {
            const data = localStorage.getItem(this.storageKey);
            this.history = data ? JSON.parse(data) : { recognize: [], register: [] };
        } catch (e) {
            console.warn('Failed to load RTF history:', e);
            this.history = { recognize: [], register: [] };
        }
    }
    
    /**
     * 保存历史数据到localStorage
     */
    saveHistory() {
        try {
            localStorage.setItem(this.storageKey, JSON.stringify(this.history));
        } catch (e) {
            console.warn('Failed to save RTF history:', e);
        }
    }
    
    /**
     * 获取当前RTF预估值（取最近5次平均）
     */
    getCurrentRTF(type = 'recognize') {
        const records = this.history[type] || [];
        if (records.length === 0) {
            return this.defaultRTF[type];
        }
        
        // 计算最近N次的平均RTF
        const sum = records.reduce((acc, rtf) => acc + rtf, 0);
        return sum / records.length;
    }
    
    /**
     * 记录一次新的RTF数据
     */
    recordRTF(type, audioDuration, processingTime) {
        const rtf = processingTime / audioDuration;
        
        // 添加到历史记录
        if (!this.history[type]) {
            this.history[type] = [];
        }
        this.history[type].push(rtf);
        
        // 保持最多N条记录
        if (this.history[type].length > this.maxHistorySize) {
            this.history[type].shift();
        }
        
        this.saveHistory();
        
        console.log(`📊 RTF记录更新 [${type}]: ${rtf.toFixed(4)} (平均: ${this.getCurrentRTF(type).toFixed(4)})`);
    }
    
    /**
     * 重置历史数据（用于测试或系统升级后）
     */
    reset() {
        this.history = { recognize: [], register: [] };
        this.saveHistory();
        console.log('🔄 RTF历史数据已重置');
    }
}

// 在VoiceprintApp类中初始化
class VoiceprintApp {
    constructor() {
        // ... 现有代码 ...
        this.rtfManager = new AdaptiveRTFManager();
    }
}
```

```javascript
/**
 * 启动识别进度（自适应RTF + 三段式弹性策略）
 */
startRecognizeProgress(audioDuration, startTime) {
    const progressBar = document.getElementById('recognize-progress-bar');
    const progressFill = document.getElementById('recognize-progress-fill');
    const progressText = document.getElementById('recognize-progress-text');
    const progressStage = document.getElementById('recognize-progress-stage');
    
    if (!progressBar || !progressFill || !progressText || !progressStage) return;
    
    progressBar.style.display = 'block';
    
    // ========== 自适应RTF预估 ==========
    const currentRTF = this.rtfManager.getCurrentRTF('recognize');
    const estimatedTime = audioDuration * currentRTF * 1000; // 转为毫秒
    
    console.log(`🎯 使用自适应RTF: ${currentRTF.toFixed(4)}, 预估耗时: ${(estimatedTime/1000).toFixed(1)}秒`);
    
    // 保存开始时间，用于后续计算实际RTF
    this.recognizeStartTime = startTime || Date.now();
    
    // 根据实际性能分配权重（基于技术白皮书架构）
    const stages = [
        // 音频预处理层 + RMS能量门限过滤层 - 3%
        { start: 0, end: 3, text: '音频预处理（采样率/声道/格式）...', weight: 0.015 },
        { start: 3, end: 6, text: 'RMS能量门限过滤...', weight: 0.015 },
        
        // 阶段1：并行感知层（SV分支 + ASR分支）- 64%
        { start: 6, end: 12, text: '【SV分支】细粒度VAD切分...', weight: 0.06 },
        { start: 12, end: 28, text: '【SV分支】声纹特征提取（FBank+ERes2NetV2）...', weight: 0.16 },
        { start: 28, end: 38, text: '【SV分支】向量比对与S-Norm评分...', weight: 0.10 },
        { start: 38, end: 42, text: '【SV分支】阈值过滤...', weight: 0.04 },
        { start: 42, end: 70, text: '【ASR分支】Faster-Whisper语音识别...', weight: 0.28 },
        
        // 阶段2：对话智能引擎 - 28%
        { start: 70, end: 78, text: '【V3.0引擎】词-说话人对齐...', weight: 0.08 },
        { start: 78, end: 85, text: '【V3.3引擎】边界校正（动态梯度）...', weight: 0.07 },
        { start: 85, end: 90, text: '【V3.4引擎】平滑修正（三明治法则）...', weight: 0.05 },
        { start: 90, end: 95, text: '【V3.0引擎】置信度感知聚合...', weight: 0.05 },
        
        // 阶段3：结果输出层 - 3%
        { start: 95, end: 98, text: '结果汇总与时间戳添加...', weight: 0.03 }
    ];
    
    // 根据权重计算每个阶段的实际时长
    stages.forEach(stage => {
        stage.duration = estimatedTime * stage.weight;
    });
    
    this.recognizeProgressInterval = null;
    let currentStageIndex = 0;
    
    const animateStage = (stageIndex) => {
        if (stageIndex >= stages.length) return;
        
        const stage = stages[stageIndex];
        const startPercent = stage.start;
        const endPercent = stage.end;
        const duration = stage.duration;
        const steps = 50; // 每个阶段50步，更平滑
        const stepDuration = duration / steps;
        const stepIncrement = (endPercent - startPercent) / steps;
        
        progressStage.textContent = stage.text;
        
        let currentStep = 0;
        let currentPercent = startPercent;
        
        // 减速策略：接近100%时减速
        const slowDownFactor = currentPercent > 90 ? 1.5 : 1.0;
        
        this.recognizeProgressInterval = setInterval(() => {
            currentStep++;
            currentPercent += stepIncrement;
            
            // ========== 三段式弹性策略 ==========
            let displayPercent;
            if (currentPercent < 90) {
                // 阶段1：0%-90% 自适应模拟区
                displayPercent = currentPercent;
            } else if (currentPercent < 95) {
                // 阶段2：90%-95% 缓冲区（极慢蠕动）
                displayPercent = Math.min(currentPercent, 95);
            } else {
                // 阶段3：95%-100% 等待后端返回
                displayPercent = 95; // 最多到95%
            }
            
            if (currentStep >= steps) {
                clearInterval(this.recognizeProgressInterval);
                progressFill.style.width = displayPercent + '%';
                progressText.textContent = Math.round(displayPercent) + '%';
                
                // 如果还没到90%，继续下一个阶段
                if (currentPercent < 90) {
                    setTimeout(() => animateStage(stageIndex + 1), 50);
                } else {
                    // 已到缓冲区，进入极慢蠕动模式
                    this.startCrawlMode(progressFill, progressText);
                }
            } else {
                progressFill.style.width = displayPercent + '%';
                progressText.textContent = Math.round(displayPercent) + '%';
            }
        }, stepDuration * slowDownFactor);
    };
    
    animateStage(0);
}

/**
 * 缓冲区极慢蠕动模式（90%-95%）
 */
startCrawlMode(progressFill, progressText) {
    let currentPercent = 90;
    
    this.recognizeProgressInterval = setInterval(() => {
        currentPercent += 0.1; // 每秒增加0.1%
        
        if (currentPercent >= 95) {
            currentPercent = 95;
            clearInterval(this.recognizeProgressInterval);
        }
        
        progressFill.style.width = currentPercent + '%';
        progressText.textContent = Math.round(currentPercent) + '%';
    }, 1000); // 每秒更新一次
}

/**
 * 完成识别进度（后端返回后调用）
 */
completeRecognizeProgress(audioDuration) {
    const progressFill = document.getElementById('recognize-progress-fill');
    const progressText = document.getElementById('recognize-progress-text');
    const progressStage = document.getElementById('recognize-progress-stage');
    
    // 清除之前的定时器
    if (this.recognizeProgressInterval) {
        clearInterval(this.recognizeProgressInterval);
    }
    
    // ========== 记录实际RTF ==========
    const actualTime = Date.now() - this.recognizeStartTime;
    this.rtfManager.recordRTF('recognize', audioDuration, actualTime / 1000);
    
    // 瞬间跳转到100%
    progressStage.textContent = '识别完成！';
    
    let currentPercent = parseFloat(progressFill.style.width) || 95;
    const steps = 10;
    const stepIncrement = (100 - currentPercent) / steps;
    
    let step = 0;
    const completeInterval = setInterval(() => {
        step++;
        currentPercent += stepIncrement;
        
        if (step >= steps) {
            clearInterval(completeInterval);
            progressFill.style.width = '100%';
            progressText.textContent = '100%';
        } else {
            progressFill.style.width = currentPercent + '%';
            progressText.textContent = Math.round(currentPercent) + '%';
        }
    }, 30); // 300ms内完成
```

```python
import numpy as np
import faiss  # 新增导入

class VectorStorage:
    def __init__(self, config_path: str = "config/model_config.yaml") -> None:
        # ... 现有代码 ...
        
        # 加载 Cohort 矩阵
        self.cohort_matrix = None
        self.cohort_path = self.config.get("storage", {}).get("cohort_path", "data/vector_db/cohort.npy")
        self.top_k = 200
        self._load_cohort()
        
        # ========== 新增：构建FAISS索引 ==========
        self.faiss_index = None
        self.use_faiss = False
        if self.cohort_matrix is not None:
            self._build_faiss_index()
    
    def _build_faiss_index(self):
        """构建FAISS索引用于加速S-Norm评分"""
        try:
            import faiss
            
            # 使用内积索引（精度与NumPy一致）
            dimension = self.cohort_matrix.shape[1]  # 192
            
            # 尝试使用GPU索引
            if faiss.get_num_gpus() > 0:
                res = faiss.StandardGpuResources()
                self.faiss_index = faiss.GpuIndexFlatIP(res, dimension)
                logger.info("✅ 使用FAISS GPU索引加速S-Norm评分")
            else:
                self.faiss_index = faiss.IndexFlatIP(dimension)
                logger.info("✅ 使用FAISS CPU索引加速S-Norm评分")
            
            # 添加Cohort向量到索引
            self.faiss_index.add(self.cohort_matrix.astype('float32'))
            self.use_faiss = True
            
            logger.info(f"📊 FAISS索引构建完成: {len(self.cohort_matrix)} 个向量")
            
        except Exception as e:
            logger.warning(f"⚠️ FAISS索引构建失败，回退到NumPy: {e}")
            self.use_faiss = False
    
    def compute_snorm_score(self, target_emb: np.ndarray, probe_emb: np.ndarray, 
                           target_metadata: Optional[Dict] = None) -> float:
        """S-Norm评分（使用FAISS加速）"""
        raw_score = self._cosine_similarity(target_emb, probe_emb)
        
        if self.cohort_matrix is None:
            return raw_score
        
        # 1. Z-Norm（针对probe）- 使用FAISS加速
        probe_flat = probe_emb.flatten().astype('float32')
        
        if self.use_faiss:
            # ✅ FAISS搜索Top-K（GPU加速）
            k = min(self.top_k, len(self.cohort_matrix))
            scores, indices = self.faiss_index.search(
                probe_flat.reshape(1, -1), k
            )
            top_scores = scores[0]  # shape: (k,)
        else:
            # NumPy fallback
            score_p = np.dot(self.cohort_matrix, probe_flat)
            k = min(self.top_k, len(score_p))
            top_k_idx = np.argpartition(score_p, -k)[-k:]
            top_scores = score_p[top_k_idx]
        
        mean_p = np.mean(top_scores)
        std_p = np.std(top_scores)
        z_score = (raw_score - mean_p) / (std_p + 1e-8)
        
        # 2. T-Norm（针对enrollment）- 从metadata读取
        if target_metadata and 'tnorm_mu' in target_metadata:
            mu_enroll = target_metadata['tnorm_mu']
            sigma_enroll = target_metadata['tnorm_sigma']
            t_score = (raw_score - mu_enroll) / (sigma_enroll + 1e-8)
            
            # 3. S-score = (Z-score + T-score) / 2
            s_score = (z_score + t_score) / 2
            return float(s_score)
        else:
            # 回退到Z-Norm
            return float(z_score)
    
    def compute_as_norm_score(self, target_emb: np.ndarray, probe_emb: np.ndarray) -> float:
        """AS-Norm评分（使用FAISS加速）"""
        raw_score = self._cosine_similarity(target_emb, probe_emb)
        if self.cohort_matrix is None:
            return raw_score
        
        probe_flat = probe_emb.flatten().astype('float32')
        
        if self.use_faiss:
            # ✅ FAISS搜索Top-K（GPU加速）
            k = min(self.top_k, len(self.cohort_matrix))
            scores, indices = self.faiss_index.search(
                probe_flat.reshape(1, -1), k
            )
            top_scores = scores[0]
        else:
            # NumPy fallback
            score_p = np.dot(self.cohort_matrix, probe_flat)
            k = min(self.top_k, len(score_p))
            top_k_idx = np.argpartition(score_p, -k)[-k:]
            top_scores = score_p[top_k_idx]
        
        mean = np.mean(top_scores)
        std = np.std(top_scores)
        return float((raw_score - mean) / (std + 1e-8))
```

## ✅ 总结

本优化方案包含4个高度可行的优化项，预期实现：

1. **用户体验大幅提升**：
   - 进度条平滑匀速移动，无跳跃
   - 进度阶段完全符合技术白皮书
   - 新增V3.4平滑修正、AS-Norm显著性检测等阶段
   - 🎯 **自适应学习机制，性能优化后自动适配**

2. **性能显著提升**：
   - RTF从0.128降至0.110（提升14%）
   - 13分钟音频从100秒降至86秒
   - 批量推理提升40%，FAISS加速提升90%

3. **实施风险低**：
   - 代码侵入性低，主要修改前端和Pipeline
   - 批量推理代码已实现，只需调用
   - FAISS有NumPy fallback，向后兼容

4. **长期可维护性**：
   - 🎯 **自适应学习机制**：RTF自动学习，无需手动调整
   - 🎯 **三段式弹性策略**：0%-90%自适应，90%-95%缓冲，95%-100%等待
   - 🎯 **localStorage持久化**：历史数据跨会话保留
   - 🎯 **性能优化自适应**：后端优化后，前端自动适配新RTF

**建议**：优先实施方案1+2+3（第一阶段），1周内完成，快速见效。方案4作为第二优先级，2周内完成。

**核心优势**：方案2的**自适应学习机制**确保了进度条在后续性能优化后仍然准确，无需手动调整权重，真正实现"一次开发，持续优化"。
