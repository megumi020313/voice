# V12.0 多人全库识别方案

## 版本信息
- **版本号**: V12.0
- **发布日期**: 2025-12-21
- **核心改进**: 多人全库识别 + 网格投票法 + 强连贯性

## 核心问题

V10.0 存在的问题：
1. **过度依赖target_uid**: 只能识别指定的目标员工
2. **无法识别多个员工**: 系统只能区分"目标员工"和"其他人"
3. **扩展性差**: 每次只能针对一个员工进行识别

## 解决方案

### 核心思想

**全库匹配 + 网格投票 + 强力平滑**

1. **全库匹配**: 每个窗口与所有注册用户比对，找出最佳匹配
2. **阈值判定**: 使用`identification_threshold`判定是否为注册用户
3. **网格投票**: 将识别结果投票到时间网格
4. **强力平滑**: 填补同一人之间的静音间隙，提高连贯性

### 算法流程

```
1. VAD检测语音区域
2. 滑动窗口提取特征
3. 每个窗口与所有注册用户比对
   - 找出最高分用户
   - 如果分数 >= identification_threshold: 确认为该用户
   - 否则: 标记为 unknown
4. 网格投票（0.1s步长）
5. 强力平滑
   - 填补同一人之间的静音（<1.5s）
   - 删除极短片段（<0.3s）
6. 合并相邻同类段
```

## 核心代码

### 分数映射函数

```python
def map_score_to_percentage(z_score, high_threshold=3.5, low_threshold=1.8):
    """
    将 Z-score 映射到 0-100 百分比
    
    映射规则：
    - z < low_threshold: 0-60%（线性）
    - z >= low_threshold: 60-90%（线性）
    """
    if z_score < low_threshold:
        # 0 → 0%, low_threshold → 60%
        percent = (z_score / low_threshold) * 60
    else:
        # low_threshold → 60%, high_threshold → 90%
        ratio = (z_score - low_threshold) / (high_threshold - low_threshold)
        ratio = min(ratio, 1.0)
        percent = 60 + 30 * ratio
    
    return percent
```

### 网格投票算法

```python
def calculate_diarization_intervals(
    raw_segments,
    total_duration,
    stride=0.1,
    max_silence_gap=15.0,
    identification_threshold=1.8
):
    """
    V12.0 多人全库识别 + 强连贯性算法
    """
    # 1. 初始化网格
    num_steps = int(np.ceil(total_duration / stride)) + 1
    grid = ["silence"] * num_steps
    grid_scores = np.zeros(num_steps)
    
    # 2. 填充网格（投票）
    for seg in raw_segments:
        center_time = seg['start'] + (seg['end'] - seg['start']) / 2
        idx = int(center_time / stride)
        
        if 0 <= idx < num_steps:
            # 全库匹配逻辑
            if seg['score'] >= identification_threshold:
                # 分数够高 -> 确认为该注册员工
                user_label = seg['user']
            else:
                # 分数不够 -> 陌生人
                user_label = "unknown"
            
            grid[idx] = user_label
            grid_scores[idx] = seg['score']
    
    # 3. 强力平滑
    # A. 同类填补：如果前后都是同一人，填补中间的静音
    fill_gap_steps = 15  # 1.5秒
    for i in range(1, num_steps - 1):
        if grid[i] == 'silence':
            # 找前面最近的非静音
            left = None
            for l in range(i - 1, max(-1, i - fill_gap_steps - 1), -1):
                if grid[l] != 'silence':
                    left = grid[l]
                    break
            
            # 找后面最近的非静音
            right = None
            for r in range(i + 1, min(num_steps, i + fill_gap_steps + 1)):
                if grid[r] != 'silence':
                    right = grid[r]
                    break
            
            # 如果前后是同一人，填补
            if left and right and left == right and left != 'unknown':
                grid[i] = left
    
    # B. 删除短片段（误报）
    i = 0
    while i < num_steps:
        val = grid[i]
        j = i
        while j < num_steps and grid[j] == val:
            j += 1
        length = j - i
        
        # 如果片段太短（<0.3s），标记为静音
        if val != 'silence' and length < 3:
            for k in range(i, j):
                grid[k] = 'silence'
                grid_scores[k] = 0.0
        i = j
    
    # 4. 转换为片段
    final_results = []
    current = grid[0]
    start_idx = 0
    
    for i in range(1, num_steps):
        if grid[i] != current:
            # 输出片段
            segment = {
                'start': round(start_idx * stride, 2),
                'end': round(i * stride, 2),
                'user': current,
                'type': 'target' if current not in ['silence', 'unknown'] else current,
                'score': round(map_score_to_percentage(grid_scores[start_idx:i].mean()), 1),
                'raw_z_score': round(grid_scores[start_idx:i].mean(), 2),
                'window_count': i - start_idx
            }
            final_results.append(segment)
            
            current = grid[i]
            start_idx = i
    
    # 最后一个片段
    if start_idx < num_steps:
        segment = {
            'start': round(start_idx * stride, 2),
            'end': round(total_duration, 2),
            'user': current,
            'type': 'target' if current not in ['silence', 'unknown'] else current,
            'score': round(map_score_to_percentage(grid_scores[start_idx:].mean()), 1),
            'raw_z_score': round(grid_scores[start_idx:].mean(), 2),
            'window_count': num_steps - start_idx
        }
        final_results.append(segment)
    
    return final_results
```

## 优势

1. **支持多人识别**: 可以识别所有注册用户
2. **无需指定target**: 自动识别所有人
3. **强连贯性**: 同一人的说话片段不会被打断
4. **准确拒识**: 陌生人会被标记为unknown

## 测试结果

- ✅ 多人对话场景：准确识别2-3个员工
- ✅ 连贯性：同一人的片段不再碎片化
- ✅ 拒识能力：陌生人正确标记为unknown
