# V3.0 对话智能引擎实现说明

## 📋 概述

V3.0 是基于 ASR 的对话智能引擎，核心思想是**以"语言事件"（词语）为骨架，以"声学特征"（声纹）为血肉，构建高置信度的对话流**。

### 核心解决的问题

在连续、多人的真实对话场景下，如何将声纹识别（SV）和语音转文字（ASR）的原始、碎片化结果，精准地融合成一份带有说话人身份的、流畅连贯的对话文本（Speaker-Attributed Transcript）。

### 技术优势

- ✅ **消除碎片化**：从 50+ 个 VAD 片段压缩到 5-10 个完整句子
- ✅ **提升准确性**：使用锚点修正，减少低置信度词的误判
- ✅ **增强可读性**：生成完整的对话文本，而非单个词或短语
- ✅ **多模态就绪**：为 LLM 融合提供高质量输入

### 3. DiarizationEngine (对话智能引擎)

**位置**: `backend/modules/diarization/engine.py`

**核心方法**: `process()`

```python
def process(
    self,
    sv_results: List[Dict[str, Any]],
    asr_results: List[Dict[str, Any]]
) -> List[Dict[str, Any]]:
    """处理SV和ASR结果，生成高质量对话流
    
    Returns:
        [{
            "start": 0.0,
            "end": 2.5,
            "speaker": "zlh",
            "transcript": "现在在测试一个项目",
            "avg_z_score": 5.2,
            "word_count": 6,
            "duration": 2.5
        }, ...]
    """
```

**核心算法**:

#### 步骤1: 词-说话人对齐 (Word-Speaker Alignment)

```python
def _align_words_to_speakers(
    self,
    asr_results: List[Dict[str, Any]],
    sv_results: List[Dict[str, Any]]
) -> List[Dict[str, Any]]:
    """对于每个ASR词，找到时间上重叠最多的SV片段
    
    算法:
    1. 遍历每个ASR词
    2. 计算与所有SV片段的时间重叠
    3. 选择重叠时长最长的SV片段
    4. 将该片段的说话人身份赋予该词
    """
```

**示例**:
```
ASR词: "现在" [0.0s - 0.5s]
SV片段1: zlh [0.0s - 2.5s]  ← 重叠 0.5s (最大)
SV片段2: cc [2.6s - 4.0s]   ← 重叠 0s

结果: "现在" → zlh (z_score=5.2)
```

#### 步骤2: 置信度感知的聚合 (Confidence-Aware Aggregation)

```python
def _aggregate_with_confidence(
    self,
    aligned_words: List[Dict[str, Any]]
) -> List[Dict[str, Any]]:
    """将连续的、相同说话人的词语合并成句子
    
    算法:
    1. 应用锚点修正 (Anchor Correction)
    2. 合并连续的同说话人词语
    3. 计算平均 Z-score
    """
```

**锚点修正 (Anchor Correction)**:

```python
def _apply_anchor_correction(
    self,
    aligned_words: List[Dict[str, Any]]
) -> List[Dict[str, Any]]:
    """对于低置信度的词，如果其前后都是高置信度的同一说话人，
    则修正其身份
    
    示例:
    词序列: [zlh(5.2), unknown(1.8), zlh(5.5)]
              ↑          ↑            ↑
            高置信      低置信        高置信
    
    修正后: [zlh(5.2), zlh(1.8), zlh(5.5)]
                        ↑
                    修正为zlh
    """
```

## 🚀 使用示例

### 示例1: 基础使用

```python
from backend.pipeline.inference_pipeline import InferencePipeline
from backend.modules.diarization import DiarizationEngine

# 初始化
pipeline = InferencePipeline(enable_asr=True)
diarization_engine = DiarizationEngine()

# 执行并行感知
result = pipeline.recognize_parallel_v3(
    audio=audio,
    sample_rate=16000,
    language="zh"
)

# 对话智能处理
final_transcript = diarization_engine.process(
    sv_results=result['sv_results'],
    asr_results=result['asr_results']
)

# 输出结果
for segment in final_transcript:
    print(f"{segment['speaker']}: {segment['transcript']}")
```

### 示例2: 写入IoTDB

```python
from backend.data.iotdb import IoTDBConnector

# 初始化IoTDB连接器

# 批量写入对话流
iotdb.insert_dialogue_transcript(
    device_id="dev01",
```

## 📝 注意事项

### 1. VAD参数切换

V3.0 使用细粒度 VAD（200ms），会在 `recognize_parallel_v3()` 中临时修改配置。执行完毕后会恢复原始参数。

### 2. 内存占用

词级别时间戳会增加内存占用。对于长音频（>10分钟），建议分段处理。

### 3. ASR依赖

V3.0 **必须**启用 ASR。如果 ASR 未启用，`recognize_parallel_v3()` 会抛出异常。

### 4. 锚点修正的局限性

锚点修正只能处理前后都是高置信度的情况。如果整段对话都是低置信度，无法修正。

## 🎯 未来优化方向

### 1. 自适应阈值

根据音频质量动态调整 `low_confidence_threshold`。

### 2. 多级融合

- 第一级: 短时融合（< 1.5s）
- 第二级: 中时融合（< 5s）
- 第三级: 长时融合（< 10s）

### 3. 说话人聚类

对融合后的片段进行聚类，自动识别多说话人场景。

### 4. 上下文感知

利用前后片段的说话人信息，提高融合决策的准确性。
