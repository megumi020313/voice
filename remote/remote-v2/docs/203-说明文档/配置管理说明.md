# 配置管理说明

## 概述

本项目采用分离的配置管理策略，区分**常量**和**配置参数**。

## 常量 vs 配置

### 常量（Constants）

**定义**：永远不会改变的固定值

**位置**：`backend/utils/constants.py`

**示例**：
- HTTP状态码：`HTTP_OK = 200`
- 业务错误码：`ERROR_CODE_VALIDATION_ERROR = 1001`
- 物理常量：`STANDARD_SAMPLE_RATE = 16000`
- 字符串常量：`UNKNOWN_USER_ID = "unknown"`

**使用方式**：
```python
from backend.utils.constants import HTTP_OK, ERROR_CODE_VALIDATION_ERROR

if response.status_code == HTTP_OK:
    return {"code": ERROR_CODE_VALIDATION_ERROR, "message": "参数错误"}
```

### 配置参数（Configuration）

**定义**：可能需要调整的参数

**位置**：`config/model_config.yaml`

**示例**：
- VAD阈值：`vad.threshold: 0.4`
- 相似度阈值：`speaker.high_threshold: 5.5`
- 批处理大小：`speaker.batch_size: 64`
- ASR配置：`asr.beam_size: 5`
- 对话智能引擎：`diarization.time_threshold: 1.5`

**使用方式**：
```python
from backend.core.config import get_config

config = get_config()

# 使用配置参数
if score > config.vad_threshold:
    # VAD检测通过
    pass

# 使用批处理大小
for i in range(0, len(data), config.batch_size):
    batch = data[i:i + config.batch_size]
    process_batch(batch)
```

## 修改参数的正确流程

### ❌ 错误做法

```python
# 在代码中硬编码
if score > 0.5:  # 魔法数字
    pass

# 或者在 constants.py 中定义可配置参数
DEFAULT_VAD_THRESHOLD = 0.5  # 这应该在配置文件中
```

### ✅ 正确做法

**步骤1：修改配置文件**

```yaml
# config/model_config.yaml
vad:
  threshold: 0.4  # 从 0.3 改为 0.4
```

**步骤2：重启服务**

配置会在服务启动时自动加载。

**步骤3：验证**

检查日志确认配置已生效。

## 配置文件结构

### model_config.yaml

```yaml
# 模型路径
model:
  eres2netv2_path: "models/eres2netv2"
  vad_path: "models/vad"

# VAD参数
vad:
  threshold: 0.3
  min_speech_duration_ms: 250
  min_silence_duration_ms: 300
  speech_pad_ms: 30

# 声纹识别参数
speaker:
  high_threshold: 5.5  # 高置信度阈值（Z-score）
  low_threshold: 2.9  # 低置信度阈值（Z-score）
  similarity_threshold: 0.5  # 声纹相似度阈值（0.0-1.0）
  top_k_ratio: 0.15  # Top-K比例
  batch_size: 64  # 批处理大小

# 音频预处理参数
audio:
  sample_rate: 16000  # 采样率（Hz）
  rms_gate_db: -100.0  # RMS能量门限（dB）
  min_segment_duration: 1.5  # 最小片段时长（秒）
  max_segment_duration: 30.0  # 最大片段时长（秒）

# ASR（自动语音识别）配置
asr:
  enabled: true  # 是否启用ASR（V3.0需要）
  language: zh  # 语言代码：zh（中文）, en（英文）, auto（自动检测）
  initial_prompt: 以下是普通话的句子。  # 初始提示词
  beam_size: 5  # Beam search大小：1（最快）, 3（平衡推荐）, 5（高质量）
  compute_type: float16  # 计算类型：float16（快速）, int8（更快但略降精度）

# V3.0 对话智能引擎配置
diarization:
  enabled: true  # 是否启用V3.0对话智能引擎
  time_threshold: 1.5  # 时间间隔阈值（秒）
  similarity_threshold: 0.7  # 声纹相似度阈值（0.0-1.0）
  low_confidence_threshold: 2.5  # 低置信度阈值（Z-score）
  vad_min_silence_ms: 200  # V3.0并行感知阶段的细粒度VAD切分（毫秒）
  min_overlap_ratio: 0.4  # 最小重叠率阈值（0.0-1.0）
  min_similarity_for_alignment: 0.65  # 词级别声纹相似度阈值
  boundary_correction:
    enabled: true  # 是否启用边界校正
    window_s: 1.5  # 边界嫌疑区的窗口大小（秒）
    min_confidence_diff: 0.1  # 最小置信度差异

# 注册参数
registration:
  num_samples: 3
  noise_augmentation:
    enabled: true
    noise_ratio_min: 0.1
    noise_ratio_max: 0.3

# 存储配置
storage:
  local_path: "data/vector_db"
  cohort_path: "data/vector_db/cohort.npy"
  redis:
    enabled: false
    host: "localhost"
    port: 6379
    db: 0

# 系统配置
system:
  device: "cuda:0"
  log_level: "INFO"
  log_file: "logs/remote-v2.log"
```

## Config 类使用指南

### 获取配置实例

```python
from backend.core.config import get_config

config = get_config()
```

### 访问配置参数

```python
# VAD参数
vad_threshold = config.vad_threshold
min_speech_duration = config.min_speech_duration_ms

# 声纹识别参数
high_threshold = config.high_threshold
low_threshold = config.low_threshold
batch_size = config.batch_size

# ASR参数
asr_enabled = config.asr_enabled
asr_beam_size = config.asr_beam_size
asr_language = config.asr_language

# V3.0对话智能引擎参数
diarization_enabled = config.diarization_enabled
diarization_time_threshold = config.diarization_time_threshold
diarization_similarity_threshold = config.diarization_similarity_threshold

# 音频参数
sample_rate = config.sample_rate
rms_gate_db = config.rms_gate_db

# 系统配置
device = config.device
log_level = config.log_level
```

### 在类中使用

```python
class AudioProcessor:
    def __init__(self):
        self.config = get_config()
    
    def process(self, audio):
        # 使用配置参数
        if len(audio) / self.config.sample_rate < self.config.min_segment_duration:
            raise ValueError("音频太短")
        
        # 处理音频
        ...
```

## 最佳实践

### 1. 参数命名规范

- 配置参数：使用描述性名称，如 `vad_threshold`, `batch_size`
- 常量：使用全大写，如 `HTTP_OK`, `ERROR_CODE_SUCCESS`

### 2. 参数分组

将相关参数分组到同一配置段：
- `vad.*` - VAD相关参数
- `speaker.*` - 声纹识别参数
- `asr.*` - ASR识别参数
- `diarization.*` - V3.0对话智能引擎参数
- `audio.*` - 音频处理参数
- `storage.*` - 存储配置（本地/Redis/IoTDB）
- `system.*` - 系统配置

### 3. 参数文档

在配置文件中添加注释说明参数含义和取值范围：

```yaml
vad:
  threshold: 0.3  # VAD检测阈值（0-1），值越大越严格
  min_speech_duration_ms: 250  # 最小语音持续时间（毫秒）
```

### 4. 默认值处理

在 Config 类中提供合理的默认值：

```python
self.batch_size = speaker_config.get('batch_size', 64)  # 默认64
```

### 5. 配置验证

在 Config 类的 `__init__` 方法中验证配置的合法性：

```python
if self.vad_threshold < 0 or self.vad_threshold > 1:
    raise ConfigError("VAD阈值必须在0-1之间")
```

## 常见问题

### Q1: 什么时候应该使用常量？

**A**: 当值永远不会改变时，如：
- HTTP状态码
- 错误码
- 物理常量
- 字符串标识符

### Q2: 什么时候应该使用配置？

**A**: 当值可能需要调整时，如：
- 模型参数
- 阈值
- 路径
- 系统设置

### Q3: 如何在开发和生产环境使用不同配置？

**A**: 可以创建多个配置文件：
- `model_config.yaml` - 默认配置
- `model_config.dev.yaml` - 开发环境
- `model_config.prod.yaml` - 生产环境

然后通过环境变量选择：

```python
import os
env = os.getenv('ENV', 'default')
config_file = f"config/model_config.{env}.yaml"
```

### Q4: 配置修改后需要重启服务吗？

**A**: 是的，配置在服务启动时加载。如果需要热更新，可以：
1. 实现配置重载机制
2. 使用配置中心（如 Consul, etcd）
3. 使用信号触发重载
