## 项目概述

**项目名称**：Remote-V2 多模态对话智能分析系统

**技术栈**：
- 后端：Python 3.11 + FastAPI + PyTorch
- 前端：HTML + JavaScript + Flask
- 模型：
  - ERes2NetV2 (声纹识别)
  - Silero VAD (语音活动检测)
  - Faster-Whisper-Large-v3 (ASR语音识别)
- 存储：本地文件 / Redis (可选) / IoTDB (时序数据)

**核心功能**：
- 声纹注册（单样本/多样本）
- V3.0并行感知识别（声纹识别 + ASR识别）
- V3.0对话智能引擎（词-说话人对齐、置信度感知聚合、边界校正）
- 多模态融合分析（阶段二，开发中）

## 核心模块说明

### 1. backend/api/ - API接口层

**职责**：处理HTTP请求，路由分发

**主要文件**：
- `app.py` - FastAPI应用入口，注册路由
- `routes/recognition.py` - 声纹识别相关接口
  - `POST /register` - 用户注册
  - `POST /register_multi` - 多样本注册
  - `POST /recognize` - 声纹识别
  - `GET /users` - 获取用户列表
  - `DELETE /users/{user_id}` - 删除用户
- `routes/config.py` - 配置管理接口
  - `GET /config` - 获取配置
  - `POST /config` - 更新配置
- `routes/health.py` - 健康检查
  - `GET /health` - 健康状态

**依赖关系**：
```
api → pipeline → {models, core, utils}
```

### 2. backend/core/ - 核心组件

**职责**：核心业务逻辑，配置管理，向量存储

**主要文件**：
- `config.py` - 配置管理（单例模式）
  - 加载 `model_config.yaml`
  - 提供全局配置访问
  - 确保必要目录存在
  
- `vector_storage.py` - 向量存储
  - `VectorStorage` - 本地文件存储
  - `RedisVectorStorage` - Redis存储
  - `get_vector_storage()` - 存储工厂
  
- `exceptions.py` - 自定义异常
  - `ConfigError` - 配置错误
  - `ModelLoadError` - 模型加载错误
  - `AudioFormatError` - 音频格式错误
  - `ModelInferenceError` - 模型推理错误

**设计模式**：
- 单例模式（Config）
- 工厂模式（VectorStorage）

### 3. backend/models/ - 深度学习模型

**职责**：模型加载、推理封装

**主要文件**：
- `speaker/eres2netv2.py` - ERes2NetV2声纹模型
  - 加载预训练模型
  - 提取声纹特征（embedding）
  - 批量推理（V14.0）
  - Mini-Batch防OOM（V14.2）
  
- `vad/silero_vad.py` - Silero VAD模型
  - 语音活动检测
  - 语音片段切分
  - 参数可配置

**模型架构**：
- ERes2NetV2：17,859,632 参数
- Silero VAD：JIT模型

### 4. backend/pipeline/ - 推理流水线

**职责**：端到端推理流程，串联各个组件

**主要文件**：
- `inference_pipeline.py` - 推理流水线
  - `register()` - 用户注册
  - `register_multi_sample()` - 多样本注册
  - `recognize()` - 声纹识别（已废弃，仅向后兼容）
  - `recognize_parallel_v3()` - V3.0并行感知模式（当前唯一引擎）
  - `transcribe_only()` - 仅ASR识别
  - `_write_v3_log()` - V3.0详细日志记录

**推理流程（V3.0）**：
```
音频输入 
  ↓
并行感知层
  ├─ 声纹识别分支：细粒度VAD切分 → 特征提取 → 说话人识别（AS-Norm评分）
  └─ ASR识别分支：完整音频 → Faster-Whisper → 词级别时间戳转录
  ↓
对话智能引擎（DiarizationEngine）
  ├─ 词-说话人对齐（时间重叠 + 声纹验证）
  ├─ 边界校正（V3.3两阶段校正）
  └─ 置信度感知聚合（锚点修正）
  ↓
最终对话流输出
```

**核心算法版本**：
- **V3.3**（当前版本）：两阶段边界校正
  - 初步对齐：词-说话人时间对齐
  - 边界校正：修正说话人切换边界的归属错误
  - 置信度感知聚合：基于Z-score的智能合并
- **V3.2**：词-说话人对齐的声纹验证（时间+声纹双重验证）
- **V3.1.1**：重叠质量检查（三把安全锁仲裁机制）
- **V3.0**：并行感知架构（声纹+ASR并行处理）

### 5. backend/utils/ - 工具函数

**职责**：纯工具函数，无业务逻辑

**主要文件**：
- `audio_utils.py` - 音频处理工具
  - `check_audio_energy()` - 能量检测
  - `calculate_snr()` - 信噪比计算
  - `augment_with_noise()` - 加噪增强
  - `calculate_diarization_intervals()` - 说话人分段
  - `map_score_to_percentage()` - 分数映射
  
- `logger.py` - 日志配置
  - `setup_logger()` - 配置日志系统
  - `get_logger()` - 获取logger实例
  
- `constants.py` - 常量定义
  - HTTP状态码
  - 业务错误码
  - 物理常量
  - 字符串常量
  
- `redis_manager.py` - Redis管理器
  - 检查Redis运行状态
  - 自动启动Redis服务

**特点**：
- 纯函数，无副作用
- 无状态，不依赖全局变量
- 可被任何模块使用

### 6. backend/common/ - 通用组件

**职责**：业务通用组件，多模块复用

**当前状态**：预留，包含config.py备份

**未来用途**：
- 权限验证
- 工作流引擎
- 通用服务

### 7. backend/data/ - 数据层

**职责**：数据存储访问，持久化层

**当前状态**：
- `iotdb/` - IoTDB连接器（多模态准备）

**未来用途**：
- SQLAlchemy模型
- 数据库操作封装

### 8. backend/modules/ - 业务模块

**职责**：完整业务功能组合，独立可运行

**当前状态**：
- `audio_analysis/` - 音频分析模块（ASR）
  - `whisper_svc.py` - Faster-Whisper ASR服务封装
  - 支持词级别时间戳转录
  - 支持多语言识别（中文、英文、自动检测）
  
- `diarization/` - 对话智能引擎模块（V3.0核心）
  - `engine.py` - DiarizationEngine对话智能引擎
  - 词-说话人对齐算法

**未来功能**：
- `llm/` - LLM接口模块（多模态融合准备）

## 开发规范

### 1. 模块划分规范

**依赖关系**：
```
tests → scheduler → modules → {data, common} → utils
controller → service → {data, modules, common} → utils
```

**禁止**：
- ❌ 反向依赖
- ❌ 循环依赖
- ❌ utils依赖其他模块

### 2. 导入路径规范

**✅ 正确**：
```python
from backend.core.config import get_config
from backend.utils.logger import get_logger
```

**❌ 错误**：
```python
from ..core.config import get_config  # 相对导入
from .logger import get_logger        # 相对导入
```

### 3. 常量 vs 配置

**常量**（`backend/utils/constants.py`）：
- 永远不变的固定值
- HTTP状态码、错误码、物理常量

**配置**（`config/model_config.yaml`）：
- 可能需要调整的参数
- 阈值、参数、路径

**使用方式**：
```python
# 使用常量
from backend.utils.constants import HTTP_OK

# 使用配置
from backend.core.config import get_config
config = get_config()
threshold = config.vad_threshold
```

### 4. 函数规范

- ✅ 必须包含类型提示
- ✅ 必须包含文档字符串
- ✅ 单一职责
- ✅ 可测试性

### 5. 日志规范

```python
from backend.utils.logger import get_logger

logger = get_logger()

logger.debug("调试信息")
logger.info("重要信息")
logger.warning("警告信息")
logger.error("错误信息", exc_info=True)
```

### 6. 异常处理

```python
from backend.core.exceptions import AudioFormatError

try:
    process_audio(audio)
except AudioFormatError as e:
    logger.error(f"音频格式错误: {e}")
    raise
```

## 快速开始

### 1. 安装依赖

```bash
conda activate dooropen_py311
pip install -r requirements.txt
```

### 2. 配置模型路径

编辑 `config/model_config.yaml`：
```yaml
model:
  eres2netv2_path: "models/eres2netv2"
  vad_path: "models/vad"
  whisper_path: "models/faster-whisper-large-v3"

# 启用V3.0对话智能引擎
diarization:
  enabled: true

# 启用ASR
asr:
  enabled: true
```

### 3. 启动服务

```bash
# 启动API服务
python -m uvicorn backend.api.app:app --host 0.0.0.0 --port 8000

# 启动Web界面
python web/app.py
```

### 4. 访问

- API文档：http://localhost:8000/docs
- Web界面：http://localhost:5000
