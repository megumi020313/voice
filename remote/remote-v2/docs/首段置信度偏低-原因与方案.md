# 首段置信度偏低：原因与方案

## 现象
每个测试音频的**首个片段的置信度（Z-score）明显低于后续片段**。

## 原因分析

### 1. 首段左侧上下文不足（主因）
- 特征提取使用 `extraction_start_sample = max(0, start_sample - extraction_pad_ms)`。
- 第一个 VAD 片段往往靠近音频起点，左侧被裁到 0，**左侧几乎没有前文**，右侧有完整 padding。
- 声纹模型（如 ERes2Net）在**左右不对称**的上下文中，边界处会看到静音/突变，embedding 质量下降，导致 Z-score 偏低。

### 2. VAD 首段前缘含非语音
- 第一段语音前缘常包含呼吸、嘴部开合、轻微噪声，VAD 从第一次检测到语音就开始切。
- 首段内“非纯净语音”占比相对高，稀释相似度。

### 3. 首段时长短
- 若首段本身较短，有效语音在整段中占比低，模型对短片段更不稳定。

---

## 方案

| 方案 | 做法 | 优先级 |
|------|------|--------|
| **A. 首段对称上下文** | 对第一个片段，当左侧不足 `extraction_pad_ms` 时，在 `extraction_audio` **左侧补零**，使长度与“左 pad + 语音 + 右 pad”一致，再送声纹。 | **已实现** |
| **B. 首段锚点修正** | 首段置信度低且第二段高置信度且第二段非 unknown 时，用第二段说话人及 z_score/confidence 拉齐首段。 | **已实现** |
| **C. VAD 首段前缘微调** | 对第一个 VAD 片段将 `start` 向后微移 50–100ms（可配置 `vad.first_segment_trim_ms`，0 关闭），减少前缘噪声。 | **已实现** |
| **D. 首段用更长上下文** | 仅对首段用 `audio[0 : end+pad]` 做特征提取，保证左侧是“静音”但长度足够，避免左边界突变。 | 与 A 二选一 |

**已实现**：方案 A（首段左侧补零）+ 方案 B（首段锚点修正）+ 方案 C（VAD 首段前缘微调）。  

**首段置信度提升三模块（已实现）**：  
- **模块1 受控 Warm-up Padding**：首段 embedding 提取音频左侧填充 300ms 低能量噪声（RMS≈5%–10% 主语音），配置 `vad.first_segment_warmup_pad_ms`（0 关闭）、`vad.warmup_noise_rms_ratio`。  
- **模块2 首段双窗口 embedding 聚合**：首段从起始与偏移 200ms 两窗口提取 embedding，L2 归一化后取均值，配置 `speaker.first_segment_dual_window_offset_ms`（0 关闭）。  
- **模块3 首段弱化 S-Norm**：首段 probe 使用缩小 cohort 比例做 Z-Norm，配置 `diarization.first_segment_snorm_cohort_ratio`（0.4 等，1.0 不弱化）。
